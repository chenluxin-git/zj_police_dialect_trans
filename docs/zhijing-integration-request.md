# 给省厅/对接人的一条消息（可直接复制发送）

> 用途：真机联调前把"我方需要的信息"和"我方提供给对方的信息"一次说清，避免来回。
> 配套：`docs/deploy-zhijing-onboarding.md`（我方联调步骤）、`deploy/README.md`（部署）。

## 一、我们这边的情况

- 应用名称：**浙江公安方言语料采集平台**（方言转译大模型语料建设）
- 部署位置：**用户域**，省厅提供的服务器上，nginx + 后端两个容器
- 对外入口：`https://<域名或IP>/`（端口 443；如平台要求子路径，请告知，我们按 `/xxx/` 构建）
- 登录方式：**从浙警智治终端/警综平台点开应用免二次登录**（数字证书在平台侧完成）
- 已按规范实现：零信任认证对接（认证回调 + 令牌校验）、零信任联动服务（接收权限更新/令牌下线指令）、
  审计服务中心上报（16 字段 + SM3 校验码 + 失败本地缓存重推）、统一用户/部门增量同步

## 二、需要贵方提供的信息（5 项）

| # | 事项 | 说明 | 用途 |
| --- | --- | --- | --- |
| 1 | **系统标准码 / requestId** | 资源管理器-我的应用里 | 审计 `sysId`、数据编目、智慧运维唯一标识 |
| 2 | **AppKey（AK）+ SecretKey（SK）** | 同上（应用系统概览） | 生成应用令牌、审计 `appSecret` |
| 3 | **上架时"认证参数"类型** | 下拉框里选的是"**动态秘钥**"还是"**令牌信息**" | 决定我们走哪条认证路径（两条都实现了，只差配置） |
| 4 | **认证 / 权限 / 审计 三个服务地址** | 省厅用户域地址；若为地市应用请给本地科信地址 | 填 `SerRzIP` / `SerQxIP` / `SJSerIP` |
| 5 | **认证回调地址要求** | 是否允许自定义路径、GET 还是 POST | 我们默认用 `https://<域名>/api/auth/zhijing/callback` |

补充确认（有则更好）：

- **统一用户组件**（部门/警员初始化与增量接口）的服务地址与接口路径 —— 用于同步警员与部门，替代我们本地开户；
  没有的话我们先用 Excel 导入开户。我们已按规范实现"**信息初始化（SJLX=1/3）+ 增量同步 + 触发链接**"，
  拿到组件调用文档即可对齐参数。
- 我方服务器到上述服务地址的**网络连通性**（是否需要开通策略）。
- 零信任侧需要回调我们的**联动服务地址**：`https://<域名>/api/rzzx/linkage`（POST，JSON，SM3 签名）。
- 若走**实时同步模式**，请把我们的触发链接登记到平台侧：
  `https://<域名>/api/admin/org-sync/init?kind=dept`（部门）、`?kind=user`（警员）。

## 三、我方提供给贵方/零信任侧的信息

| 项 | 值 |
| --- | --- |
| 认证回调地址 | `https://<域名>/api/auth/zhijing/callback`（支持 GET/POST） |
| 联动服务地址 | `https://<域名>/api/rzzx/linkage`（接收 `role-update`/`token-offline`/`token-online`/`token-renew`） |
| **同步触发链接**（实时模式要求） | `https://<域名>/api/admin/org-sync/init?kind=dept`（部门）/ `?kind=user`（警员）；需管理员 Bearer 令牌，可选 `&token=<触发口令>` |

## 四、联调顺序（我方计划）

1. **mock 模式**自证链路（免登录 → 进首页 → 审计落台账）——已完成，可截图；
2. 拿到第 1、2、3、4 项后切 **live**：从平台点开应用应**直接进首页**（判定标准）；
3. 打开审计上报与统一用户同步，请贵方在审计侧/用户侧确认收到数据；
4. 智慧运维（Matomo 埋点、日志采集、稳定性探针、浙警智评悬浮球）需要贵方给 **siteId** 与采集端配置，
   其中稳定性探针（GAPM-agent）官方覆盖 Java/.NET/PHP，**我们是 Python 后端**，请确认是"提供替代方案"还是"免接"。

## 五、常见联调异常对照（便于快速定位）

| 现象 | 多半原因 |
| --- | --- |
| 跳回登录页并提示"平台认证未通过" | 回调地址或"认证参数"类型与上架配置不一致 |
| 提示"令牌无效或不存在"（1001/1003） | 令牌没取到：前置代理把 `RZZX-*` 头吞了 |
| 提示"权限冻结"（0003） | 平台侧未给该用户开通本应用权限 |
| 进得去但审计侧无数据 | `sysId`/`appSecret` 与注册信息不一致，或审计地址不通（看 `audit_send` 表 message） |
| 人员/部门数据不进来 | 统一用户组件地址或接口路径与组件调用文档不一致（看 `/api/auth/zhijing/self-check` 的 `org_sync`） |
